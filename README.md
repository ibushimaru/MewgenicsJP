# Mewgenics 日本語MOD（配布終了）

Mewgenics は 2026年9月6日のアップデートで公式に日本語対応しました。
このMODは役目を終えたので配布を終了します。遊んでいただきありがとうございました。

## MODを外す方法

1. ゲームフォルダを開く（Steam → Mewgenics → 右クリック → 管理 → ローカルファイルを閲覧）
2. `version.dll`、`MewgenicsJP_progress.exe`、`MewgenicsJP` フォルダ、`resources.gpak.bak` を削除する
3. Steam → Mewgenics → 右クリック → プロパティ → インストール済みファイル → ファイルの整合性を確認
4. ゲームを起動し、言語設定で日本語を選ぶ

Steam でアンインストール → 再インストールする場合も、手順 2 は必要です。Steam は MOD のファイルを消しません。
