# Mewgenics 日本語MOD

Edmund McMillen制作「Mewgenics」の日本語翻訳MODです。

## インストール方法

1. [Releases](../../releases) から最新の `MewgenicsJP-vX.X.X.zip` をダウンロード
2. 任意の場所に展開
3. `install.bat` をダブルクリック

Steamのゲームフォルダは自動で検出されます。

## アンインストール

2つの方法があります:

- `uninstall.bat` をダブルクリック (バックアップから復元)
- Steam → Mewgenics → プロパティ → インストール済みファイル → ゲームファイルの整合性を確認

## 動作要件

- Windows 10/11 (64bit)
- Steam版 Mewgenics
- Python不要 (同梱済み)

## ゲームアップデート後

Steamのアップデートでゲームファイルが上書きされた場合、`install.bat` を再度実行してください。
バックアップは自動的に新しいバージョンに更新されます。

## 技術情報

- フォント: Yusei Magic
- ワードラップ: BudouX + ZWSP (Zero Width Space) による自然な改行
- パッチ方式: gpak デルタリパック + exe バイナリパッチ
