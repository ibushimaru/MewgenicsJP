============================================================
  Mewgenics 日本語MOD
============================================================

■ インストール方法

  1. このフォルダ内の install.bat をダブルクリック
  2. Steamのゲームフォルダが自動で検出されます
  3. インストール完了後、ゲームを再起動してください
  4. Settings → Language → 日本語 を選択

  ※ 管理者権限は不要です
  ※ Pythonのインストールは不要です (同梱済み)


■ アンインストール方法

  方法1: uninstall.bat をダブルクリック
         (バックアップからゲームファイルを復元します)

  方法2: Steam → Mewgenics → プロパティ
         → インストール済みファイル
         → ゲームファイルの整合性を確認


■ ゲームアップデート後

  Steamのアップデートでゲームファイルが上書きされた場合、
  install.bat を再度実行してください。
  バックアップは自動的に新しいバージョンに更新されます。


■ トラブルシューティング

  Q: install.bat が一瞬で閉じる
  A: install.bat を右クリック → 「管理者として実行」を試してください

  Q: ゲームフォルダが見つからないと表示される
  A: 手動でゲームフォルダのパスを入力してください
     例: D:\SteamLibrary\steamapps\common\Mewgenics

  Q: テキストが文字化けする
  A: ゲーム内の Settings → Language → 日本語 を選択してください

  Q: ワードラップがおかしい (テキストが1行に詰まる)
  A: exeパッチが適用されていない可能性があります
     install.bat を再度実行してください


■ 技術情報

  - フォント: Yusei Magic
  - ワードラップ: BudouX + ZWSP による自然な改行
  - パッチ方式: gpak デルタリパック + exe バイナリパッチ
